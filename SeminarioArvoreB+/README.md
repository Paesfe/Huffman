# Seminário: Índices em Bancos de Dados com Árvore B+

Material de apresentação sobre o uso de **Árvores B+** como estrutura de indexação em Sistemas Gerenciadores de Banco de Dados (SGBDs), desenvolvido para a disciplina de Estrutura de Dados.

**Autores:** Arthur Guilherme Correia, Felipe Paes Alves, Victor Corcetti Guerra

## Referências

- **CORMEN, T. H. et al.** *Algoritmos: Teoria e Prática* — Cap. 18 (Árvores B).
- **SILBERSCHATZ, A.; KORTH, H. F.; SUDARSHAN, S.** *Sistema de Banco de Dados* (7ª ed.) — Cap. 11, com foco na seção 11.3 (índices em banco de dados).
